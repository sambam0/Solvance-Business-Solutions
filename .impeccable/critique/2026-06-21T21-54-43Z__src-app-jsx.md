## Anti-Patterns Verdict

**LLM assessment:** Site is competent but structurally monotonous. Every section follows heading -> subheading -> card grid. SpringCard sameness — every surface is identical bg-2/line/24px/cursor-glow. No section-level art direction. Hero underpowered (weight 500 vs spec 700). Zero imagery. Terminal and mesh canvas are genuinely good; the rest is well-executed template.

**Deterministic scan:** 11 undocumented colors (use-case accents), 14 off-system radii, legacy border-left stripe on .case-card (banned pattern, dead code). No gradient-text violations.

## Overall Impression

Solid B. Design system well-built, terminal pane is genuinely good, mesh canvas is bespoke and impressive, copy is credible. Reads as well-executed SaaS landing page, not Awwwards production. Gap is art direction per section, visual surprise, and absence of scroll-stopping moments.

## What's Working

1. Terminal Pane — GSAP TextPlugin typing + staggered reveals, macOS chrome, realistic agent output
2. Mesh Network Canvas — hand-drawn canvas animation, IntersectionObserver gating, DPR scaling, reduced-motion fallback
3. Copy — specific, credible, not hype. FAQ answers are honest and detailed.

## Priority Issues

### [P1] Section monotony
Every section follows identical heading/subheading/card-grid pattern. Violates "each section should feel art-directed individually."
Fix: Redesign 2+ sections with fundamentally different layouts.

### [P1] No visual peak moment
No full-viewport visual event or unexpected layout break. Mesh canvas is close but doesn't take over.
Fix: Full-viewport takeover for systems section or typographic interstitial between sections.

### [P2] Hero h1 underweight
font-weight 500 vs design system spec of 700. Reads as subheading weight.
Fix: Set to 700. Consider stronger headline copy.

### [P2] Zero imagery
No photographs, illustrations, or visual proof. Brand register: "text-only pages where typography alone carries the entire visual weight are the failure mode."
Fix: Add team photos, agent system screenshots, proof elements.

### [P2] ~1000 lines dead CSS
Legacy styles from removed pages (.case-card border-left, .badge2w, .steps, .pricing, .tier, .quotes). Third of CSS is dead weight.
Fix: Audit classes against JSX and remove unreferenced selectors.
